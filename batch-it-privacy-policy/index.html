Batch It Privacy Policy

Last updated: 10 October 2026

Batch It is a macOS app with a Safari web extension that finds the photos and videos on the page you are viewing and saves the ones you choose to your Downloads folder. It is made by Nicholas Naude.

The short version: Batch It collects no data about you. It has no servers, no accounts, no analytics, and no third-party code. Everything it does happens on your Mac, and the only network traffic it creates goes directly from your Mac to the websites that host the media you are looking at.

What Batch It does not do

  • It does not collect, store, or transmit personal information.
  • It does not collect browsing history, page content, or the media it finds.
  • It does not use analytics, crash reporting, advertising, or tracking of any kind.
  • It does not operate any server and never sends anything to the developer.
  • It does not share anything with third parties.
  • It does not require an account or sign-in.

The App Store privacy label for Batch It is "Data Not Collected".

When the extension can see a web page

The extension uses Safari's activeTab permission. It has no access to any website until you click the Batch It button in the Safari toolbar. Safari asks you to allow access to that site the first time, and you can change that choice at any time in Safari Settings under Websites.

When you click the button, the extension runs a small script on the current page only. The script looks for image and video elements, picture sources, links to media files, and CSS background images, and collects their web addresses along with their dimensions and, where the page already knows it, their file size. It does not read the text of the page, form fields, cookies, or anything you type. The results exist only in the popup window and are discarded when it closes. Nothing is scanned in the background or on pages where you have not clicked the button.

Network requests the extension makes

All requests go straight from your Mac to the website that hosts the media. No request passes through any service run by the developer. Three kinds of request are made:

  1. Checking each item. As soon as the popup lists the media it found, it asks the hosting server for the first byte of each file. This is how it learns the file size and whether the file can actually be downloaded, so it can grey out items that will not work. These requests happen even if you download nothing.
  2. Video previews. For videos, the extension fetches enough of the file to decode a single poster frame, which is shown as the thumbnail in the popup.
  3. Downloads. When you click a download button, the extension fetches the selected files and saves them to your Downloads folder.

Each of these requests includes the address of the page you were viewing as the Referer header, because many sites refuse to serve media without it, and a standard Safari-style User-Agent header. Beyond that, the requests carry no identifying information. The websites you fetch media from will see these requests the same way they would see your browser loading the page, and their own privacy policies govern what they do with that.

What is stored on your Mac

  • Downloaded files are saved to your Downloads folder with their original file names. You control them from there.
  • One preference flag is kept in the extension's local storage. It holds no personal information.
  • Short diagnostic notes may be written to the macOS system log if a scan fails, for example "scan returned 0 items". These notes never include web addresses or page content, stay on your Mac, and are managed by macOS like any other app log.

Nothing else is written anywhere. The companion app's window exists only to open Safari's extension settings and stores nothing.

Permissions and sandboxing

Both the app and the extension run inside the macOS App Sandbox. The extension has exactly three capabilities beyond the sandbox default:

  • Outgoing network connections, used only for the media requests described above.
  • Read and write access to your Downloads folder, used only to save the files you ask for and to reveal them in Finder.
  • Safari web extension permissions for activeTab, scripting, storage, and native messaging, which let the popup scan the page you clicked on, keep its single preference, and hand download requests to the sandboxed native component.

Children

Batch It is a general-purpose utility, is not directed at children, and collects no information from anyone.

Changes to this policy

If a future version of Batch It changes what it does with data, this policy will be updated and the date at the top revised. Because the app does not collect anything, there is nothing to migrate or delete when the policy changes.
